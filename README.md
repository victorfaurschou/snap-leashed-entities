# Snap Leashed Entities

**Snaps leashed entities back to you when they fall too far behind.**

Available on [Modrinth](https://modrinth.com/mod/snap-leashed-entities) and [CurseForge](https://www.curseforge.com/minecraft/mc-mods/snap-leashed-entities).

## 💡 Example

[![1](https://raw.githubusercontent.com/victorfaurschou/snap-leashed-entities/26.1/.github/examples/1.gif)](https://raw.githubusercontent.com/victorfaurschou/snap-leashed-entities/26.1/.github/examples/1.gif)

## 📌 Notes

- Leads aren't technically made unbreakable, but in practice they become effectively unbreakable in almost all circumstances.
- Only entities leashed directly to a player are handled. Entities leashed to a non-player anchor (e.g. a boat leashed to another boat) are not covered.

## 🔗 Dependencies

### Required
- [Fabric Loader](https://fabricmc.net/use/)
- [Fabric API](https://modrinth.com/mod/fabric-api)
